# Small-Model-Lab

# Pre Experiment Thoughts & Intuition (ENTIRELY HAND WRITTEN, NO AI)
I created this project to get a feel of how model performance changes with model size (number of params).

I was wrongly under the belief that every AI problem should be solved with an LLM, even simpler tasks like classification of tasks. When Jev released I became more aware of smaller models & classifiers (yes, I know Jev, is more then just a classifier), and now I want to understand what these different sized models are capable of and how I can levarage their strengths.

Will give my thoughts and the results of all of these models, and what I see as potential use cases for them.
